# Laboratorio de Píxeles

Tres demos interactivas para una exposición de gráficos por computadora:

1. **Mezclador RGB**: mezcla aditiva y subpíxeles (`#rgb`)
2. **Malla y luz**: de vértices a wireframe y sombreado de Lambert (`#malla`)
3. **Rasterización**: qué píxeles cubre un triángulo (`#raster`)

Página única en HTML, CSS y JavaScript, sin dependencias.
