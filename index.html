        Mostrar
        
        
        
      

      
Arrastra los vértices A, B y C. Un píxel se pinta solo si su centro queda dentro de los tres bordes del triángulo (prueba de funciones de borde).

      
// para cada píxel (x, y):
w0 = borde(B, C, p);
w1 = borde(C, A, p);
w2 = borde(A, B, p);
if (w0 >= 0 && w1 >= 0 && w2 >= 0)
    pintar(x, y);
